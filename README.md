# Tic Tac Toe (HTML & JavaScript)

Ein einfaches Tic Tac Toe-Spiel für zwei Spieler – direkt im Browser spielbar.  
Keine Installation nötig, einfach die HTML-Datei öffnen.

## 🔧 Funktionen

- 3x3 Spielraster mit X und O
- Spielerwechsel mit Statusanzeige
- Gewinnererkennung und Unentschieden
- Neustart-Button

## ▶️ Starten

1. Diese Repository/Datei herunterladen oder klonen
2. `index.html` im Browser öffnen

## 🛠️ Technologien

- HTML
- CSS
- JavaScript (Vanilla)
